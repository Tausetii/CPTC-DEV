# Wormhole Resort & Casino — HR Portal

Internal HR portal for The Wormhole Resort & Casino employees. Built with Flask + SQLite.

## Setup

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
python seed.py
python app.py
```

Then open http://127.0.0.1:5000

## Default credentials

See `seed.py` for the seeded employee accounts.
